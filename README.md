# Todo-List

Um aplicativo simples de lista de tarefas desenvolvido com o objetivo de praticar conceitos básicos de desenvolvimento front-end e organização de código.
Este projeto foi criado para fins de estudo e para compor meu portfólio, colocando em prática conceitos como manipulação do DOM, eventos e lógica de programação.


# Funcionalidades

- Adicionar novas tarefas

- Marcar tarefas como concluídas

- Remover tarefas

- Interface simples e intuitiva

- Dados salvos localmente


# Tecnologias utilizadas

- HTML

- CSS

- JavaScript
